- Si combinano due approcci distinti per valutare la robustezza di un sistema o di una rete.
- # Vulnerability assessment:
	- si identificano, quantificano e qualificano le possibili vulnerabilità presenti 
	- si rilevano eventuali punti deboli e falle di sicurezza 
- # Penetration testing:
	- si tentano di sfruttare le vulnerabilità di un sistema per penetrarlo 
	- si cerca quindi di simulare un attacco reale per testare le misure di sicurezza.
